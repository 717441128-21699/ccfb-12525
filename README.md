# 板书提取器

从学校录播教室的录像里，把老师写在白板上的板书一页一页自动抠出来。
TypeScript 实现，WebCodecs 解码，图像处理全部在 GPU 着色器（WebGL2）里完成。

## 功能

- **课程管理**：添加 MP4 录像，或一键生成"虚拟老师 + 白板"的合成演示课程
- **白板自动定位**：取散布全片的关键帧做逐像素最大值融合（老师走来走去会被"最亮值"抹掉，
  边框被挡住一截也能从其它帧补全），再对融合图做边缘行列投影 + 直线拟合得到四边；
  不准时可以拖动四角手动微调
- **人体遮挡处理**：笔迹颜色（红/蓝/黑）连续稳定 K 帧才提交进板书状态 —— 老师身体不是
  笔迹色，永远不会被提交；笔被挡住时计数冻结，**人走开后那片板书才更新**；
  另有"细特征"过滤（笔迹 4px 内必有白板，头发/衣物的暗团块内部不算）
- **翻页检测**：3 秒滑动窗口累计擦除量 + 笔迹量跌破峰值阈值 → 擦掉重写算新页；
  小范围涂改不翻页；一页写一半又补的，合成最终状态
- **每页信息**：书写起止时间、6×4 格书写热度（标出写得最久的区域）
- **红/蓝/黑三个笔迹图层**：可单独开关显示
- **导出**：多页 PDF（内嵌 JPEG）+ PNG 图片 ZIP 打包
- **性能**：0.5s 采样 + GPU 处理，45 分钟的课远小于 2 倍时长即可处理完

## 运行

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 构建到 dist/
```

## 自测（合成录像 → 提取 → 对比真值）

```bash
npm run build
npm run selftest   # 无头 Chrome 跑 test.html，输出逐项 PASS/FAIL
```

自测流程：canvas 画虚拟老师在白板前讲课（3 页板书，含擦掉重写、写一半走开再补、
小范围涂改）→ H.264 编码成 MP4 → 走完整提取管线 → 断言页数、每页内容（IoU）、
颜色图层、书写起止时间、最热区域、处理耗时全部与教案设定一致。

## 结构

```
src/
  mp4/mp4.ts          最小 MP4 复用/解复用（avc1/AVCC，非分片）
  decode/decoder.ts   WebCodecs 解码（顺序帧流 / 关键帧抽取）
  gpu/                WebGL2 封装 + GLSL（矫正、时序累积、分层、展示）
  pipeline/
    boardDetect.ts    白板四边自动定位
    extractor.ts      核心提取管线（翻页、页统计）
    render.ts         页面合成（图层开关、热度叠加）
  export/             手写 PDF / ZIP
  testgen/            教案（真值）+ 合成录像渲染编码
  test/selftest.ts    端到端自测
  ui/app.ts           页面交互
```

## 已知限制

- MP4 仅支持 avc1（H.264）非分片封装；其它封装需先转码
- 老师穿纯黑/纯红/纯蓝衣服且长时间静止时，理论上可能被误判为笔迹
  （细特征过滤 + 时序稳定投票已大幅缓解）
